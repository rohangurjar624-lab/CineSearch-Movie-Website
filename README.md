# 🎬 CineSearch - Movie Search Website

## 📌 Project Overview

CineSearch is a responsive and interactive Movie Search Website developed using HTML, CSS, and JavaScript. Users can browse movies, search for movies, filter movies by genre, view movie details, and save their favorite movies.

## 🎯 Project Objective

The objective of this project is to demonstrate web development concepts learned during the internship, including HTML, CSS, JavaScript, DOM Manipulation, Events, Arrays, Objects, and Responsive Design.

## ✨ Features

- 🔍 Search Movies
- 🎭 Filter Movies by Genre
- 🎬 Dynamic Movie Cards
- ℹ️ Movie Details Popup
- ❤️ Add Movies to Favorites
- ❌ Remove Movies from Favorites
- 💾 Local Storage Support
- 📱 Responsive Design
- ⚡ Interactive User Interface
